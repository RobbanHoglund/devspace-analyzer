# Reference documentation

Rules are intentionally more conservative than a package manager's generic cleanup command. Consult the installed tool's own documentation and configuration before acting on a finding.

- Gradle user-home layout and automatic cleanup: https://docs.gradle.org/current/userguide/directory_layout.html
- npm cache purpose and commands: https://docs.npmjs.com/cli/v12/commands/npm-cache/
- pip cache behavior: https://pip.pypa.io/en/stable/topics/caching/
- Tauri platform prerequisites: https://v2.tauri.app/start/prerequisites/
- Tauri Rust command interface: https://v2.tauri.app/develop/calling-rust/
- Tauri dialog plugin: https://v2.tauri.app/plugin/dialog/
- Tauri Windows packaging: https://v2.tauri.app/distribute/windows-installer/
- Rust Windows file attributes: https://doc.rust-lang.org/std/os/windows/fs/trait.MetadataExt.html

Project marker detection and directory names are evidence of possible category membership, not proof of disposability. Sources do not establish that a particular package or artifact on a particular computer can be recovered.
