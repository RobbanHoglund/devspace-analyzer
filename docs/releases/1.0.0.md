# DevSpace Analyzer 1.0.0 for VS Code

Understand which projects and developer caches use your storage, inspect the
evidence, and follow manual cleanup instructions with a same-scope before/after
comparison. DevSpace never runs cleanup or project commands.

## Highlights

- Interactive folder treemap and ecosystem distribution, with breadcrumbs,
  Back/Forward navigation, searchable findings and project recovery plans.
- Compact Overview with clear review candidates, protected data and scan coverage.
- Manual npm, pnpm and pip cache guidance: exact target, copyable command,
  consequences and official documentation. Scan again after making your own changes.
- Faster native scanning with bounded directory lookahead and Windows metadata reuse.
- Shared Robban Höglund portrait branding with JVMScope, local assets and support
  for VS Code dark, light and high-contrast themes.
- Apache-2.0 license and bundled third-party notices.

## Install

Choose the `.vsix` for your local machine:

| System | Package suffix |
| --- | --- |
| Windows x64 | `win32-x64.vsix` |
| Linux x64, glibc | `linux-x64.vsix` |
| macOS Intel | `darwin-x64.vsix` |
| macOS Apple silicon | `darwin-arm64.vsix` |

In VS Code 1.85 or later, use **Extensions → … → Install from VSIX…**, select
the file, then open **DevSpace** in the Activity Bar. The scanner is included;
no separate language runtime is needed. Shared-cache scanning is opt-in.

`SHA256SUMS` contains the SHA-256 of each VSIX and `SOURCE.json`. `SOURCE.json`
records the exact source revision, successful CI runs and original artifact digests.

## Scope and limits

This GA release covers the VS Code extension in trusted **local desktop windows**.
Remote SSH, WSL, Dev Containers, virtual workspaces and vscode.dev scanning are
not supported. Restricted Mode permits demo viewing only. Results measure logical
file lengths, not guaranteed reclaimable space. Linked paths are rejected and
inaccessible or bounded traversal is disclosed in coverage.

The separate Windows desktop application remains an **unsigned preview** and
is not included in these GA assets. Marketplace distribution is not part of
this release; install the versioned VSIX directly.
